# Phaeton licensing

Licensing help has moved to the Phaeton website:

- [Activation](https://phaeton.virtunet.io/docs/activation): activate an
  installation with a license.
- [License pricing](https://phaeton.virtunet.io/pricing) and the
  [license and purchase terms](https://phaeton.virtunet.io/terms).
- [Software license](https://phaeton.virtunet.io/terms/EULA.md).

The Phaeton version that linked here is out of date. Install the update it
offers (version 0.60.0), let Phaeton restart, then check for updates again to
get the current release. [Updates](https://phaeton.virtunet.io/docs/updates)
explains updating in more detail.
